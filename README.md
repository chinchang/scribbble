# Scribbble
A beautiful screen annotation Mac app for creators, educators and presenters.

## Download app

[Download app](https://github.com/chinchang/scribbble/releases/latest/download/Scribbble.dmg)

## Using the app

- Toggle the app using `Option+Tab`
- To add license, click the "Scribbble" icon in menu bar, goto "Manage License"

## Website translations

The marketing pages (homepage, `/for/*`, `/vs/*`, `/best/*`) are served in 8 languages — English at root URLs, plus `es`, `zh`, `ja`, `de`, `hi`, `nl`, `fr` under `/{locale}/...`. The blog and `/tools/screenshot-annotate` are English-only.

Translations are generated by a script and committed to the repo; builds never call any API.

### Editing copy

1. Edit the **English** source only:
   - UI copy → `messages/en.json`
   - Page data (personas, comparisons, listicles) → `lib/*.ts`
2. Run the translation script (only new/changed strings are sent to the API):
   ```bash
   pnpm translate              # all languages
   pnpm translate --locale es  # one language
   pnpm translate --dry-run    # preview what would be translated
   ```
3. Commit the updated `messages/*.json`, `lib/i18n/data/**` and `scripts/i18n-lock.json`.

The script needs `OPENAI_API_KEY` (put it in `.env.local`). Model defaults to `gpt-5-mini`; override with `OPENAI_MODEL`.

### Fixing a bad translation

Edit the string directly in `messages/{locale}.json` or `lib/i18n/data/{locale}/*.json` and commit — manual fixes are never overwritten unless the English source changes.
